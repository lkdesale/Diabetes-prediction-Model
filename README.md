## 📌 Overview

This project leverages supervised machine learning algorithms to analyze medical data and estimate whether a patient is at risk of diabetes. The application is designed with a simple and interactive user interface, enabling users to input health metrics and receive instant predictions.

## ✨ Features

- Data preprocessing and exploratory data analysis (EDA)
- Multiple ML models for prediction and comparison
- Real-time diabetes risk prediction
- Flask-based web application with interactive UI
- User-friendly input form and prediction results
- Model evaluation and performance analysis

## 🛠️ Tech Stack

- **Programming Language:** Python 3
- **Machine Learning:** Scikit-learn
- **Web Framework:** Flask
- **Data Processing:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Frontend:** HTML, CSS, Bootstrap
- **Development Tools:** Jupyter Notebook, Git, GitHub

## 🤖 Machine Learning Models Used

- Logistic Regression
- Random Forest Classifier
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
